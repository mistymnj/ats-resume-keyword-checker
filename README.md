# ATS Resume Keyword Checker

A simple Python tool that checks if your resume has the keywords from a Job Description.

It helps freshers make ATS-friendly resumes and improve their chances of getting shortlisted.

## What It Does

- Compares your Resume with a Job Description
- Shows your Match Score in %
- Lists Found Keywords
- Lists Missing Keywords you should add

## What I learned

- How ATS software scans resumes and why keywords matter
- How to compare two texts using Python string matching
- How to calculate match percentage from found and missing keywords
- How to turn a real problem (resume rejection) into a working tool
